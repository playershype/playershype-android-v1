# Rendimiento de aplicaciones

Referencia: video 75550.mp4, «31 trucos» de Anton. Evalúa cada punto según la arquitectura, el volumen y la evidencia. Empieza por los flujos que el usuario abre y mide la versión entregada.

| Puntos del video | Criterio de entrega | PlayersHype Android 1.4.2 |
| --- | --- | --- |
| 1, 2, 15, 29. Esqueletos, WebP/AVIF, imágenes diferidas, fuentes propias y pocos pesos | Reserva espacio para el contenido. Prioriza la imagen principal. Comprime las imágenes nuevas y comprueba compatibilidad. | Inicio muestra un esqueleto y difiere imágenes secundarias. Admin exporta fotos nuevas en WebP con respaldo JPEG y difiere miniaturas. Las fuentes de Inicio usan la pila del sistema. |
| 3, 4, 5, 12, 16. Deduplicación, debounce, paginación, timeouts y solicitudes en paralelo | Comparte lecturas concurrentes, limita cada llamada externa, difiere búsquedas remotas por pulsación y pagina colecciones grandes. | Admin comparte la descarga y abre con su borrador cuando dispone de una base guardada. Las lecturas independientes se solapan. Inicio recibe solo los campos visibles. La búsqueda actual es local y el histórico se consulta en HypePredict. |
| 6, 9, 10, 27. CDN, Brotli/gzip, Redis y caché de estáticos | Verifica la caché y compresión de la plataforma. Usa Redis cuando exista un cuello de botella compartido y una política de expiración. | Recursos de interfaz empaquetados, publicación estática y última copia válida local. La descarga pública revalida mediante ETag. La publicación ya comprime el bloque de datos. |
| 7, 13, 14. Tareas en segundo plano, streaming de IA e interfaz optimista | Saca el trabajo lento del hilo de interfaz. Muestra progreso o cambios reversibles. Confirma las escrituras solo tras validarlas. | Sincronización pública en segundo plano y borradores locales. Los botones de publicación esperan confirmación. Esta versión no consume una API de IA generativa. |
| 8, 17, 19, 24, 25, 28. N+1, índices, proximidad, proyección, pool y balanceo | Revisa consultas reales y el plan de ejecución. Configura región, conexiones y escalado cuando haya servicios propios y una carga que lo justifique. | La proyección nativa aplica el principio de devolver solo los campos usados. La ruta de publicación actual no opera una base de datos ni servidores propios. |
| 11, 20, 21, 22, 23, 26. Dependencias sin uso, render en servidor o en compilación, terceros diferidos, JavaScript por ruta, listas virtuales y renders repetidos | Mide tamaño y costo por ruta. Retira código con evidencia de uso, conserva accesibilidad y navegación al virtualizar y omite renders si el contenido visible coincide. | Inicio y HypePredict ya cargan vistas separadas. Inicio omite renders cuando la vista permanece igual. El visor PDF sigue disponible para las importaciones. |
| 18, 30, 31. Trazas, medición real y pruebas en móvil y red lenta | Captura latencia, carga y errores sin datos privados. Prueba arranque, flujos clave, caché y fallos en la versión entregada. Distingue mediciones locales de telemetría de usuarios. | Pruebas de integración, comprobación del tamaño del JSON con el código nativo y pruebas Android en CI. La telemetría de usuarios y una medición formal en red lenta quedan pendientes. |

La configuración publicada usada en la prueba ocupó 7 537 163 bytes en el formato nativo. La proyección de Inicio ocupó 1 956 bytes el 1 de noviembre de 2026, con una pista publicada, y 1 820 bytes el 3 de noviembre, sin pistas publicadas. Son bytes antes de compresión y sin metadatos de sincronización. La cifra describe el paso de datos a Inicio, no el tráfico de descarga o el tiempo de arranque de un dispositivo.
