# 1.4.4 — explicit publication scope

The restored workspace includes a sealed Camarero card (Nov 5) and an unsealed Horseshoe card (Nov 3). Earlier publishing actions passed the entire library to the exporter. This patch selects only cards explicitly marked `preRaceFrozen:true` at the common snapshot boundary, blocks an all-draft nonempty request, preserves drafts in local storage and leaves existing published historical config intact. The Control Center shows the included and excluded cards before publication.

The public copy withholds HypePick 6 when its structured legs, combinations or stated mathematical costs disagree; no wager, cost or private structure is rewritten. A legacy `quickHits.longshot` reference is published as Huevazo, separately from Value Play. The explicit exporter now retains `huevazo` and `publicationProfile` so existing public role/validation metadata survives projection. Display decisions use their source text when supplied. No HypeScore engine, weight, reading, seal or historical result changes.

Version code 12 uses the same pinned permanent certificate as 1.4.3. The Admin can update an installed 1.4.3 without removing local data or its native encrypted publisher credential. Older discarded-key versions still require migration. User App 1.4.3 already consumes the same public contract and does not need replacement for this Admin-only fix.

Relevant security controls are input/projection validation (6/7/18), preserving unpublished/private data (2/3/23), and scoped verification (26/27). No permission, native origin, crypto, dependency or network policy changes. Existing full UI/sync, native security, PDF/import, signature, artifact scan and emulator gates remain required. New checks cover sealed/draft separation, missing seals, unchanged saved data, invalid/valid ticket arithmetic and legacy Huevazo mapping. Scope preview is a bounded in-memory scan with no new request; public preparation clones only eligible cards. This is not a claim that a seal flag proves temporal pre-race validity or that a phone publication has already occurred.
