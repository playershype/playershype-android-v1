# 1.1.0 Preview — two-app integration
Added separate public/Admin modules, shared hardened shell, original HypePredict packaged renderers, internal public routing, cache projection/history, native save/share/import mediation and local Admin configuration drafts. Removed legacy permanent Live token persistence and private embedded data.

PASS evidence is limited to the actual CI audit/tests/lint/signature/hash outputs attached to the build. DOM tests cover public track/card/race/horse/Tale/back/history and Admin startup plus malicious draft validation.

PARTIAL: original feature parity, offline refresh against live publication, Admin operational Control Center (technical JSON drafts), lifecycle restoration, export rendering on devices, Live/TV/Latest dynamic content. BLOCKED: authenticated Core connection, server role enforcement, secure token lifecycle, publish/rollback and end-to-end changes reaching the public APK. NOT RUN: physical-device installation and complete visual/parity acceptance.

Both APK files are testing artifacts. Their existence does not mean the full ecosystem is production-ready.

Additional limitation: an exported Admin HTML snapshot renders standalone, but re-exporting HTML or importing PDF from that standalone browser file requires the installed Admin app; packaged export resources are not embedded recursively. No Android device was attached (adb devices returned an empty list).
