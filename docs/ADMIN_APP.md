# Admin Preview
The original HUB was extracted from the supplied Admin APK. Private embedded cards/workspace were removed from the package; import your own workspace through the Android document picker. The original card, track, scratches, Postmortem, sponsor, Broadcast and export tools remain in the original module. A DOM fixture verifies startup and import controls; complete parity and file flows require device testing.

Control Center stores local JSON drafts for Home, tracks, Live, TV, Latest, sponsors and a private prompt/config registry. It validates shape, compatibility, links and disallows credentials/executable content; it compares current and proposed drafts and exports JSON. This is a technical Preview editor, not the finished operational form UI. Its local bounded history is not a tamper-evident server audit log.

Login, publication and server rollback are deliberately disabled. No identity provider, Core source, role model, or verified write API was supplied. Keystore token storage is consequently not implemented and no token is collected. These remain mandatory before enabling remote administration.

The legacy permanent localStorage Live bearer was removed. Local backups/exports may contain private user-imported analysis: they leave the sandbox only after a user-selected save/share action.
